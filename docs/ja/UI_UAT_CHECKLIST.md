# ご本人の受入確認票

機械側の全検証の完了宣言ではありません。未検証の条件は[UI_TEST_REPORT](UI_TEST_REPORT.md)を先に確認してください。環境不足の例外を受け入れたという回答は、操作成功とは別に記録します。

## 専用版を開く

通常画面: `pwsh -NoProfile -File tools/validation/Start-Uat.ps1`

フォルダ画面: `pwsh -NoProfile -File tools/validation/Start-Uat.ps1 -FolderMode`

スクリプトが表示するコピー素材のパスを取り込みに使います。専用プロファイル `artifacts/ui-validation/profiles/uat-user` を再利用するので、再起動後の保存を確認できます。コピー素材はCC0 RAW、埋め込みJPEGからの派生ペア、生成JPEG、長い日本語名、意図的に壊した画像を含みます。実撮影ペアとは区別してください。

## 手順なしの参考評価

詳しいガイドを読む前に、次を試して記録してください。仕様を知っている可能性があるため初心者向けの客観的評価とは扱いません。

| 課題 | 実施すること | 記録すること |
|---|---|---|
| UAT-01 開く・選別 | コピー写真を取り込み、星・お気に入り・リジェクトを変更して再起動 | 取り込み先と選択対象が分かったか、評価が残ったか |
| UAT-02 探す・比較 | ファイル名検索、2／3／4枚比較、拡大、固定、入替 | 目的の写真へ到達できたか、固定と移動の意味が分かったか |
| UAT-03 整理 | 複数をチェック、タグ、親子コレクション、手動イベント、自動候補の確定 | 1枚選択と一括対象を混同しなかったか |
| UAT-04 出力 | クロップして書き出し、同名をもう一度出力、破損画像の失敗を確認 | 元画像が残ったか、失敗と再試行の方法が分かったか |
| UAT-05 設定 | 設定を保存して再起動、取消、ショートカット変更、管理編集保存 | 保存と取消の違い、反映時期が分かったか |

各課題について `成功／失敗、実際の結果、迷い、誤操作、読みにくい箇所、発見しやすさ・理解しやすさ・見やすさ（各1～5）と理由` を返してください。4以上は改善目標です。点数より具体的な問題を優先します。

## ガイド付きの全入口確認

[USER_GUIDE](USER_GUIDE.md)に沿って[操作台帳](UI_OPERATIONS.csv)を確認します。ボタン・右クリック・キー・ダブルクリック・ホイール・ドラッグは同じ機能でも別入口です。台帳には内部コード候補もあるため、人間が直接操作する行と区別してください。

| 操作ID | 成功／失敗／未実施 | 実際の結果 | 迷い・誤操作・読みにくさ | 評価と理由 | 証拠・希望 |
|---|---|---|---|---|---|
| 例: MainWindow.ExportSelectedPhoto | | | | | |

正常、取消、空選択、入力訂正、終端、再実行と再起動を含めます。削除・JPEG埋込はコピーだけを使い、対象と影響を読んでから実行してください。大量件数・エラー注入の機械検証は別証拠で管理します。

実画面で文字欠け、ボタンに到達不能、色だけの状態区別、見えないフォーカス、入力中の誤評価があれば、画面・解像度・倍率と具体的操作を記録してください。複数画面がある場合は倍率の異なるモニター間で移動・境界・最大化／復元、ダイアログ位置も確認します。

Mustは受入前に修正、Should延期は合意と代替手順を記録、Couldはバックログです。分類への異議も記録してください。結果受領・修正・再確認まで本人確認待ちとし、mainにはmergeしません。
