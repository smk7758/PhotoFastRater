# ユーザーガイド

更新日: 2026-10-07。対象: Windows 11 x64。検証の実施状況は[UI検証結果](UI_TEST_REPORT.md)、入口ごとの確認票は[操作台帳](UI_OPERATIONS.csv)を参照してください。

## 起動と終了

通常起動はライブラリ画面を開きます。フォルダモードは `PhotoFastRater.UI.exe --folder "C:\写真"` で開けます。パスを省略した `--folder` は空のフォルダ画面を開きます。

検証用には `PhotoFastRater.UI.exe --data-dir "C:\PfrTest\profile"` を使います。絶対パスが必要で、`--folder` と併用できます。DB・設定・キー・セッション・ログ・キャッシュを専用領域に保存します。指定なしの起動は従来の保存先を使います。検証では原本をコピーして使用してください。

終了はウィンドウ右上の閉じるボタンです。書き出し中は先に中断して状態を確認してください。比較・ビューア・プレビューの独立ウィンドウも閉じます。評価はDB保存が先、XMPは後から同期するため、同期状態を確認してください。

## ライブラリへ写真を登録する

1. 上部の写真取り込みボタンを押し、写真のあるフォルダを選びます。
2. 下部の状態表示で進捗とエラー件数を確認します。中断ボタンで停止できます。確定済みの写真は残ります。
3. 同じフォルダを再実行しても同じ正規化パスは重複登録されません。読み込み直す場合は一覧の再読み込みを使います。

一覧は必要なページを追加読み込みします。保持する軽量データは最大1,280件で、チェック対象もこの範囲です。グリッド／ツリーを切り替え、ツリーはフォルダを展開して写真を選びます。サムネイルサイズのスライダーで表示密度を変えます。写真がない場合は取り込み先とフィルターを確認してください。

## 1枚を選ぶことと、一括対象のチェック

写真カードのクリックは、右側に評価・情報を表示する1枚の選択です。左上のチェックはタグ付けやバッチ出力の対象です。選択枠とチェックは別々です。全チェック／解除は現在読み込んだ写真が対象です。

右側の0～5の星ボタンで評価し、お気に入り／リジェクトを切り替えます。写真にフォーカスがあるときは0～5、F、Xも使えます。矢印で移動、Enterでビューアを開きます。文字入力欄や設定操作中には写真のショートカットを発動させません。Tab／Shift+Tabはフォーカス移動です。

評価はSQLiteへ確定してから表示を更新し、XMP sidecarへ同期します。保存失敗は成功扱いになりません。リンクされたRAW＋JPEGは同じ評価を保存します。再読み込み／再起動後の値と、同期状態を確認できます。

## 検索と欠損写真

検索欄にファイル名・パス・タグを入力します。入力から200ms後に検索します。空にすると検索条件を解除します。「欠損のみ」は原本が見つからない記録だけを表示します。結果が空の場合は検索文字と欠損条件を確認します。原本を元の場所へ戻して再スキャンすると欠損状態を確認し直せます。

## 閲覧と比較

ビューアでは画像・撮影情報を確認し、星ボタンまたは0～5、F、Xで評価します。Esc／Qで閉じます。RAWは埋め込みJPEGを表示し、RAW現像は行いません。埋め込み画像がない／破損している場合は読み込み失敗として扱います。

比較は基準写真を選び、2枚・3枚・4枚比較を開きます。必要な写真が足りない場合は対象を増やしてください。各ペインでCtrl＋ホイールによるズーム、ドラッグによるパンを行います。「ズームとパンを同期」で全ペインまたは個別操作を切り替えます。「表示をリセット」で戻します。「固定」は次の組へ進んでもその写真を残し、「右へ入替」はペインを入れ替えます。「次の組」で固定していない写真を進めます。自動送りをONにすると評価後に進みます。比較で移動できるのは現在保持している最大1,280件の範囲です。

## タグ・コレクション・イベント

チェックした写真へ「タグを付ける」でタグを一括追加します。空の名前や未選択の場合は表示された案内に従ってください。タグは検索に使用できます。

「タグ／コレクション」タブでルートコレクションまたは選択コレクションの子を作り、「コレクションへ」でチェック写真を追加します。コレクションを選んで含まれる写真を確認します。

写真を1枚選択し、「イベント」タブでイベント名を入力して「イベント作成」を押すと手動イベントを作成できます。イベント削除は確認後に関連付けを解除し、写真ファイルと評価は残します。取消では変更されません。「自動候補を確認」は候補を表示するだけです。内容を見て「候補を確定」を実行します。同じ候補を再確定しても重複しません。

## フォルダモード

「フォルダを開く」で対象を選びます。通常ライブラリとは別のセッションとして評価を保存します。「保存」は現在のセッションを保存し、「再読み込み」はファイルと保存済み情報を読み直します。

評価下限0～5、すべて／JPEG／RAW、未評価のみ、ファイル名、日付範囲で絞り込みます。日付の開始が終了より後なら修正してください。「リセット」で条件を解除します。矢印で移動、Home／Endで先頭／終端、F5で再読み込み、Ctrl+Oで開く、0～5・F・Xで評価します。画面のボタンからも同じ操作を実行できます。

設定でRAW＋JPEGをまとめるとペアを1項目として表示し、展開や「ペアファイルを表示」で相方を確認できます。まとめたペアの評価とフラグは相方にも保存します。独立プレビューは「プレビュー」で開き、選択に連動します。インラインの画像・撮影情報も確認できます。

「DBに追加」はセッションをライブラリへ転送します。確認を承認すると登録済み写真の星・お気に入り・リジェクトをセッションの値へ置き換えます。星を下げた変更も対象です。失敗した場合、完了済みのまとまりは残り、再実行できます。XMPの未同期分は再起動時にも再処理されます。

写真のダブルクリック／右クリックの「開く」は関連付けアプリを開きます。右クリックから写真の再読み込み、エクスプローラー表示、ファイル名・パスのコピーもできます。外部アプリがない場合はWindowsの関連付けを確認してください。

「JPEGへ評価を書き込む」は原本JPEGへの明示的変更です。対象と確認内容を読み、コピーで試してください。取消では書き込みません。DB登録解除は原本を残し、ごみ箱移動は原本にも影響します。実行前に対象を確認し、失敗時は残ったファイルとDBの状態を確認してください。

## 出力

単体出力は「エクスポート」タブでSNSサイズを選び、「選択写真を単体出力…」から保存先を選びます。ビューアではInstagram／Twitter／Facebookを選び、枠・EXIF表示・左上／右上／左下／右下／カスタム位置を指定して「エクスポート」を押します。カスタム位置はスライダーまたはプレビュー内の位置操作で調整します。

一括出力はカードのチェックを付け、「エクスポート」タブを開きます。

1. JPEG／PNG／TIFF、命名規則、JPEG品質、メタデータ保持を指定します。命名に `{name}`・`{id}`・`{date}` を使えます。
2. 回転なし／90／180／270度、最大幅・高さ、枠、EXIF表示を設定します。一括出力のEXIF位置は左下固定です。
3. クロップを使う場合は有効化し、X・Y・幅・高さを0～1の画像比率で指定します。1:1／4:3／3:2／16:9のプリセットは中央基準です。範囲外・空・不正な値は修正します。
4. 「チェック写真を書き出す」で保存先を選び、進捗と結果を確認します。

元画像は変更せず、同名出力は連番で保存します。元ファイルを出力先に指定しても上書きしません。中断しても完了した出力は残ります。欠損・破損・未対応画像は失敗一覧を確認し、原因を解消して失敗分を再試行します。単体のSNS出力と一括の形式・クロップ設定は別の経路です。

## 設定と管理フォルダ

通常画面の設定ではキャッシュ保存先・容量・メモリ関連値・GPU利用を設定して保存します。不正な数値は直してから保存してください。専用プロファイルではキャッシュ先を専用領域に固定します。キャッシュをクリアすると再生成されます。GPU変更の実描画方式は再起動後に確認してください。

フォルダモードの設定は、サムネイルサイズ、RAW＋JPEGまとめ表示、名前欄のEXIF、レンズ／撮影設定／日時／機種名、メモリ警告、フル画像のメモリ上限を指定します。RAM表示と推奨値を参考にします。「保存して閉じる」で反映、「キャンセル」で破棄、「設定ファイルを開く」でJSONを確認できます。直接編集前はコピーを退避してください。

ショートカット設定で操作のキー・修飾キーを変更できます。重複、未指定、予約キーTab／Escは保存できません。保存、キャンセル、初期化を区別してください。旧設定にTabがある場合もフォーカス移動が優先されます。

管理フォルダは追加して有効／再帰を編集し、「編集を保存」を押します。除外パターンは追加／削除し、有効、Wildcard／Regex／Exact、パターン、説明を編集して保存します。不正な正規表現は修正してください。保存後に選択フォルダの「スキャン」または「一括スキャン」を実行し、状態欄を確認します。管理登録の削除は原本削除とは異なります。

## 保存先と復旧

通常のDBは `%LOCALAPPDATA%\PhotoFastRater`、移行前バックアップはその `Backups`、日次ログは `Logs` です。専用プロファイルでは指定ディレクトリ配下になります。設定やキーの従来保存先は[データ保護](DATA_SAFETY.md)を参照してください。

復旧前はアプリを終了し、現在のDBとバックアップの両方を削除せず退避します。壊れた設定JSON・権限不足・保存エラーの場合も原本を保持してログを確認してください。未検証の実機条件と残件は[UI検証結果](UI_TEST_REPORT.md)に記録しています。
