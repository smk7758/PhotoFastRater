# ユーザーガイド

更新日: 2026-09-05

## 最初の選別

通常画面では**インポート**からフォルダを登録します。処理中も登録済み写真を閲覧でき、ステータス欄には確認件数と個別エラー数が表示されます。中断する場合は**キャンセル**を押してください。再実行時は同じ正規化パスを重複登録しません。

写真カードをクリックして選び、0～5キーで星評価、Fでお気に入り、Xでリジェクトを切り替えます。評価は先にSQLiteへ確定し、その後XMP sidecarへ同期されます。色だけでなく星、文言、枠で状態を確認できます。

## 検索と整理

検索欄は入力から200ms後にファイル名、パス、タグを横断検索します。**欠損のみ**を有効にすると元ファイルが見つからない記録だけを表示します。

複数写真を整理するには、カード左上のチェックを付けます。**タグを付ける**で同じタグを一括付与できます。**タグ／コレクション**タブではルートまたは選択項目の子コレクションを作り、**コレクションへ**でチェック写真を追加します。一括対象は最大1,280枚です。

## 比較

基準写真を選択して**2枚比較**、**3枚**、**4枚**を押します。比較画面ではズームとパンの同期を切り替え、ペインの固定・入替ができます。評価後の自動送りは既定OFFです。現在の一覧ページ群（最大1,280件）を越える比較移動は未対応です。

## イベント

選択写真から手動イベントを作成できます。自動整理は**自動候補を確認**で候補だけを作り、内容を確認後に**候補を確定**します。同じ候補を再確定しても重複しません。

## クロップと書き出し

カード左上で対象をチェックし、**エクスポート**タブを開きます。JPEG／PNG／TIFF、`{name}`・`{id}`・`{date}`を使う命名規則、品質、回転、最大寸法、枠、EXIF表示を指定できます。

クロップは画像全体を0～1としたX、Y、幅、高さで指定します。1:1、4:3、3:2、16:9プリセットは中央基準です。元画像は変更されず、同名出力には連番が付きます。途中でキャンセルしても完了済み出力は残り、欠損・破損・未対応RAWは結果一覧から失敗項目だけ再試行できます。

## データ復旧と診断

DB移行前のバックアップは`%LOCALAPPDATA%\PhotoFastRater\Backups`、日次ログは`%LOCALAPPDATA%\PhotoFastRater\Logs`にあります。復旧前にアプリを終了し、現在のDBと復旧元の両方を削除せず退避してください。詳しくは[データ保護](DATA_SAFETY.md)を参照してください。
