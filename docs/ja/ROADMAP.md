## 常用ベータ基盤

- [x] 再現可能なlocked restoreとWindows CI
- [x] Core／Infrastructure／UI境界と短命DbContext

## ベータ判定前に必要

- [ ] フォルダモードの全件ViewModel保持をデータ仮想化へ移行
- [ ] JPEG／RAW混在10万実画像で初回走査、再走査、キャンセル、メモリを実測
- [ ] 100%／200% DPI、キーボード、スクリーンリーダーを実機確認
- [ ] インストーラーと更新・ロールバック手順を選定して署名済みパッケージを検証
- [ ] XMP双方変更時の比較・解決画面とペア既存差分の選択画面
- [ ] イベント候補生成を全件読込からストリーミング集計へ変更
