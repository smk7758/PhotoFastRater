# 実装状況

最終更新: 2026-10-06

この文書は、コードから確認できる現在の機能と、常用ベータまでの作業状況を管理します。READMEや設計文書が先行して実装済みと誤認されないことが目的です。

## 現在利用できる機能

- フォルダの直接走査、EXIF読取、RAW埋め込みJPEGのプレビュー
- RAW+JPEGのペア表示
- レーティング、お気に入り、リジェクト、基本フィルター
- SQLiteへの写真登録、管理フォルダ、除外パターン
- 枠とEXIFオーバーレイを含むJPEG書き出し
- キーボードショートカットの変更
- FTS5によるファイル名・パス・タグの横断検索（200msデバウンス）
- 選択写真からの手動イベント作成と単体JPEG書き出し
- ユーザー設定のLocalApplicationDataへの原子的保存
- 2～4枚比較、ペイン固定・入替、同期ズーム／パン切替、評価後の任意自動送り
- 複数タグの一括付与と、タグ名を含むFTS5横断検索
- 親子関係を持つ階層コレクションと、選択写真の一括追加
- 欠損写真だけの抽出
- イベント自動候補のプレビューと、再確定しても重複しない登録
- JPEG／PNG／TIFFのバッチ書き出し、非破壊クロップ、回転、命名衝突回避
- バッチ書き出しの進捗、キャンセル、写真単位の部分失敗と再試行
- 日次ローカルログ、win-x64自己完結publish profile、主要WindowのDPI丸めとAutomation名

## 既知の制約

- ライブラリ一覧は最大1,280件のページデータに制限済みですが、フォルダモードはまだセッション全件をメモリへ保持するため、単一フォルダ10万枚対応は未完了です。
- RAWは埋め込みJPEGの表示であり、RAW現像や色管理には対応していません。
- イベント候補の作成は大規模ライブラリでは全件を読み込むため、ストリーミング集計への移行が残っています。
- RAWフル現像を伴う書き出しは未対応で、バッチでは写真単位の未対応結果になります。
- XMP sidecar書込キューは実装済みですが、双方向の自動競合解決画面は未完了です。
- 比較画面は現在読み込まれている最大1,280件内を移動します。別ページをまたぐ連続比較は未完了です。
- タグとコレクションの名称変更・削除は未完了です。

- Windows CIでlocked restore、書式、Release build、テスト、依存監査を実行
- ソースの`Cache`ディレクトリを誤って除外しない`.gitignore`
- 高重大度警告が出ていた暗号・SQLiteネイティブ依存の更新
- 暗室を意図したInk／Slate基調の共通テーマと、色以外の文言を併用した状態表示
- 検索中の旧ページ・画像要求キャンセル、インポートのキャンセルと部分エラー件数表示
- キャッシュクリア時の元画像保護と`_GARBAGE`への回復可能な退避
- XMP同期ワーカーをUIの同期コンテキストから分離し、終了時のデッドロックを防止（STAコンテキストの回帰テスト付き）
- ReadyToRun配布に必要なパックをpublish時に固定復元し、Windows CIの配布検証を修正

## 導入済みのアーキテクチャ境界

- `PhotoFastRater.Infrastructure`を新設し、DB、migration、EXIF、走査、キャッシュ、画像処理、書き出しをCoreから移動
- Coreへ評価、検索カーソル、比較、クロップ、書き出しレシピとI/O抽象を追加
- Repositoryを`IDbContextFactory`による短命Contextへ変更し、読み取りを追跡なしに変更
- MainWindowとFolderModeWindowをウィンドウ単位のDIスコープへ変更
- ViewModel内のサービスロケータを廃止し、ユーザー対話とWindows Shell操作を抽象化
- 写真ファイル削除を完全削除からWindowsごみ箱への移動へ変更

詳細は[アーキテクチャ](ARCHITECTURE.md)を参照してください。

## 実装順序

1. DB・XMP同期と元画像保護
2. 10万枚向け増分走査、ページング、仮想化、キャッシュ
3. 選別UIと2～4枚比較
4. 検索、タグ、階層コレクション、イベント
5. 非破壊クロップとバッチ書き出し

各段階では、関連するテストと文書を同じcommitで更新します。
