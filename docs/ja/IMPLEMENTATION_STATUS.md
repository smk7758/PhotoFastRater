# 実装状況

最終更新: 2026-09-05

この文書は、コードから確認できる現在の機能と、常用ベータまでの作業状況を管理します。
READMEや設計文書が先行して実装済みと誤認されないことが目的です。

## 現在利用できる機能

- フォルダの直接走査、EXIF読取、RAW埋め込みJPEGのプレビュー
- RAW+JPEGのペア表示
- レーティング、お気に入り、リジェクト、基本フィルター
- SQLiteへの写真登録、管理フォルダ、除外パターン
- 枠とEXIFオーバーレイを含むJPEG書き出し
- キーボードショートカットの変更

## 既知の制約

- 一覧表示はまだ全件をメモリへ保持し、10万枚対応は未完了です。
- RAWは埋め込みJPEGの表示であり、RAW現像や色管理には対応していません。
- メイン画面の検索、設定保存、イベント、書き出しには未接続の操作があります。
- XMPサイドカー同期、比較表示、タグ、階層コレクション、クロップは未実装です。

## 完了済みの安定化

- NuGetパッケージの中央バージョン管理とロックファイル
- Windows CIでのlocked restore、書式、Release build、テスト、依存監査
- ソースの`Cache`ディレクトリを誤って除外しない`.gitignore`
- 高重大度警告が出ていた暗号化／SQLiteネイティブ依存の更新

## 実装順序

1. データ保護とI/O境界
2. DB・XMP同期
3. 10万枚向け増分走査、ページング、仮想化、キャッシュ
4. 選別UIと2～4枚比較
5. 検索、タグ、階層コレクション、イベント
6. 非破壊クロップとバッチ書き出し

各段階では、関連するテストと文書を同じコミットで更新します。
