# 実装状況

最終更新: 2026-09-05

この文書は、コードから確認できる現在の機能と、常用ベータまでの作業状況を管理します。READMEや設計文書が先行して実装済みと誤認されないことが目的です。

## 現在利用できる機能

- フォルダの直接走査、EXIF読取、RAW埋め込みJPEGのプレビュー
- RAW+JPEGのペア表示
- レーティング、お気に入り、リジェクト、基本フィルター
- SQLiteへの写真登録、管理フォルダ、除外パターン
- 枠とEXIFオーバーレイを含むJPEG書き出し
- キーボードショートカットの変更

## 既知の制約

- 一覧表示はまだ全件をメモリへ保持し、10万枚対応は未完了です。
- RAWは埋め込みJPEGの表示であり、RAW現像や色管理には対応していません。
- メイン画面の横断検索、設定保存、イベント、書き出しには未接続の操作があります。
- XMP sidecar同期、比較表示、タグ、階層コレクション、非破壊クロップは未完了です。

## 完了済みの安定化

- NuGetパッケージの中央バージョン管理とlock file
- Windows CIでlocked restore、書式、Release build、テスト、依存監査を実行
- ソースの`Cache`ディレクトリを誤って除外しない`.gitignore`
- 高重大度警告が出ていた暗号・SQLiteネイティブ依存の更新

## 導入済みのアーキテクチャ境界

- `PhotoFastRater.Infrastructure`を新設し、DB、migration、EXIF、走査、キャッシュ、画像処理、書き出しをCoreから移動
- Coreへ評価、検索カーソル、比較、クロップ、書き出しレシピとI/O抽象を追加
- Repositoryを`IDbContextFactory`による短命Contextへ変更し、読み取りを追跡なしに変更
- MainWindowとFolderModeWindowをウィンドウ単位のDIスコープへ変更
- ViewModel内のサービスロケータを廃止し、ユーザー対話とWindows Shell操作を抽象化
- 写真ファイル削除を完全削除からWindowsごみ箱への移動へ変更

詳細は[アーキテクチャ](ARCHITECTURE.md)を参照してください。

## 実装順序

1. DB・XMP同期と元画像保護
2. 10万枚向け増分走査、ページング、仮想化、キャッシュ
3. 選別UIと2～4枚比較
4. 検索、タグ、階層コレクション、イベント
5. 非破壊クロップとバッチ書き出し

各段階では、関連するテストと文書を同じcommitで更新します。
